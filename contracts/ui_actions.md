# UI 액션 [요구사항]

이 파일은 **[요구사항]** 이다. 에이전트(이 저장소)가 보내는 `action` 이벤트의 의미와, on-stage 가 정하고 해야 할 일을 적는다.
페이로드 모양은 `guide_events.py`, 예시는 `fixtures/guide_events_sample.json` 이 기준이다. 설계 근거는 `docs/design.md` §4, §14.3.

## 에이전트가 보내는 것

| 액션            | 페이로드                                | 단계                      |
| --------------- | --------------------------------------- | ------------------------- |
| `focusArtist`   | `{ slug }`                              | 2b (지금)                 |
| `openTour`      | `{ slug }` (`section` 은 보내지 않는다) | 2b (지금)                 |
| `highlightCity` | `{ slug, city }`                        | 4단계. 아직 보내지 않는다 |

- 답변 텍스트가 끝난 뒤, `done` 앞에 **한 번만** 보낸다. 순서는 `text_delta... → action → done` 이다.
- 에러·취소로 끝나는 요청에서는 보내지 않는다.
- `slug` 는 서버가 `/api/artists` 로 만든 enum 으로 검증한 값만 보낸다. 한 답변에서 여러 번 호출되려 하면 마지막 유효한 것 하나만 보낸다.
- 액션 도구 호출은 `tool_status` 로 보내지 않는다. 프런트 사전에 `tool.focusArtist`, `tool.openTour` 키를 추가하지 않아도 된다.

## 의미

| 액션          | 의미                                                                                                                                                                                          |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `focusArtist` | 궤도 화면에서 카메라를 해당 아티스트로 옮긴다.                                                                                                                                                |
| `openTour`    | 해당 아티스트 페이지로 이동하고 투어 섹션이 보이게 한다. 카메라 포커스 → 페이지 이동 → 섹션 이동의 연출 순서와 자동 이동/칩 방식은 on-stage 가 결정한다. 에이전트는 `openTour` 하나만 보낸다. |

## on-stage 가 정해줘야 할 값

| 항목                         | 현재 상태                                                                                                                                                                                       |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `openTour.section`           | 값 목록이 on-stage 계약에 없다. 에이전트는 `section` 을 보내지 않는다. on-stage 가 값(예: 섹션 id)을 정하면 "계약 갱신" 태스크로 `guide_events.py`, fixture, 이 문서, 프롬프트를 함께 갱신한다. |

## on-stage 가 해야 할 일

1. **알 수 없는 액션은 무시한다.** `type` 이 모르는 값이면 실행하지 않고 오류도 보여주지 않는다. 답변은 그대로 표시한다.
2. **실행 전에 `slug` 를 다시 검증한다.** `/api/artists` 응답의 `slug` 목록에 없으면 실행하지 않는다 (서버 검증을 신뢰하지 않는다).
3. **실행이 실패하거나 무시돼도 답변은 항상 표시한다.**
4. **모르는 필드는 무시한다.** `openTour.section` 이 나중에 추가될 수 있다. 없을 때(`undefined`)도 정상으로 처리한다.
5. **요청마다 `context { view, slug? }` 를 보낸다.** 안 보내면 에이전트는 현재 화면을 "알 수 없음"으로 보고 `focusArtist` 를 보내지 않을 수 있다.
6. **계약 테스트:** 이 저장소의 `fixtures/guide_events_sample.json` 을 복사해 zod 스키마로 검증한다 (설계 §8.1).
